# MMMU 실험 비교 분석 — Qwen3-VL-4B-Instruct

기존 실험(베이스라인, 시드 42, 09-21)과 현재 실험(best, 시드 3407, 09-23)을 조건·과정·결과에서 비교하고, 결과를 분과·과목·응답 유형·문항 유형·이미지 수·보기 수·응답 길이·잘림·정오 전이로 나눠 분석했습니다. 시드만 바꾼 재현 실행(1234, 09-25)으로 실행 간 노이즈를 실측했습니다. 모든 수치는 `results/*/scored.jsonl`, `summary.json`, `by_subject.csv`에서 계산했습니다. 상호작용 차트가 있는 원본은 아티팩트 페이지이며, 이 문서는 그 마크다운판입니다. 제출 보고서는 [reports/mmmu_baseline.md](../reports/mmmu_baseline.md)입니다.

## 6. 해석

**밝혀진 것**
- 격차의 원인은 지식이 아니라 답만 내는 응답이었습니다. 프롬프트 한 문장으로 605건이 0건이 됐고 공식 파서 기준 +32문항입니다.
- 예산·해상도·시드는 점수를 움직이지 않았습니다. 90문항 control이 베이스라인과 같았고 시드 재현은 +0.67%p였습니다.
- 강제 CoT는 조건부 CoT보다 나은 점이 없었습니다.
- 주관식은 채점 규칙 문제가 컸습니다. 6→22.

**남은 것**
- 수렴 실패 77건, 루프 60건. 예산으로 안 풀리므로 학습 대상입니다. 전부 회수하면 약 +3%p.
- 풀이를 끝내고도 틀린 261건(정상 종료 823건 중 32%). 지식·판독·추론의 한계이며 이제 풀이가 남아 원인 분류가 가능합니다.
- Tech & Engineering 55.7%, Health & Medicine 67.3%가 개선 여지가 큽니다.

**주의**
- 시드만 바꾼 재실행에서 134문항이 뒤집혔고 전체 점수는 +0.67%p 움직였습니다. 이항분포 표준편차 1.58%p와 일치합니다.
- 과목 단위는 최대 6문항이 움직여 근거가 되지 못합니다. 분과 단위도 ±3~5%p가 노이즈이므로 파인튜닝 효과는 시드 2~3개 평균으로 보고해야 합니다.
- 두 점수(엄격·파이프라인)를 항상 함께 보고하고 공식 수치와 비교할 때 어느 쪽인지 명시해야 합니다.

## 7. 재현

```bash
bash scripts/run_mmmu_eval.sh --preset baseline --out outputs/raw.jsonl        # 시드 42, 8192 토큰, MMMU 공식 프롬프트
bash scripts/run_mmmu_eval.sh --preset best --out outputs/best.jsonl           # 시드 3407, 32768 토큰, Qwen 프롬프트 + CoT + fallback
bash scripts/run_mmmu_eval.sh --preset best --seed 1234 --out outputs/best_seed1234.jsonl
bash scripts/run_mmmu_eval.sh --preset best --model_path /path/to/finetuned     # 또는 --lora_path DIR
python scripts/compare_runs.py raw best best_seed1234
```
